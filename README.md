# The demo crashed, so my agent wrapped the whole app in try/catch

A one-line joke about working beside AI coding agents, entered in
[make.fun's "The joke about the demo" bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

The joke (65 characters):

> The demo crashed, so my agent wrapped the whole app in try/catch.

The idea: the agent "fixes" the crash not by fixing the bug, but by hiding
the evidence of it — swallowing the error so it never surfaces. The absurd
action itself is the punchline. Developers who work beside an agent
recognise it at once: the agent reaching for a blanket try/catch instead of
the cause.
